# Epic 3: Agent Microservice Core (LangGraph)

**Context**: The core logic of the application. Implements the Router -> Subgraph architecture. Located in `services/agent-api`.

**Key Design Docs**:
- `docs/agents/implementation.md` (Detailed Class/Node Design)
- `docs/agents/architecture.md` (High level flow)
- `docs/agents/retrieval_config.md` (RAG parameters)

## Task 3.1 — State Definition & Configuration

**Goal**: Define the shared state schema.

**Reference**: `implementation.md` Section 3.1.

**Implementation**:
- Define `AgentState` TypedDict (messages, specific keys for `retrieval_metrics`, `graph_context`, `tool_results`).
- Create configuration loader (load retrieval params from `retrieval_config.md`).

**Deliverables**: `state.py` file with fully typed schema.

## Task 3.2 — Retrieval Orchestrator Subgraph

**Goal**: The "RAG" engine.

**Reference**: `implementation.md` Section 3.2 (Retrieval Orchestrator).

**Implementation**:
- `QueryExpander`: LLM node to generate search queries.
- `ParallelRetrievers`:
    - Vector search (Text/Table/Image).
    - Keyword search (Postgres `tsquery`).
- `Fusion`: RRF algorithm implementation.
- `Reranker`: Voyage AI Client integration.

**Deliverables**: A standalone Subgraph that takes a query and returns `final_context`.

## Task 3.3 — Router & Input Normalization

**Goal**: Handle entry and intent classification.

**Reference**: `implementation.md` Section 3.2 (InputNormalizer & Router).

**Implementation**:
- `InputNormalizer`: Load doc scopes, resolve `visibility_override` (using `shared_data_layer`).
- `Router`: GPT-5-mini prompt to classify into `{Informational, Analyst, Numerical, Vision}`.

**Deliverables**: Nodes that transition state from Start -> Route.

## Task 3.4 — Informational & Analyst Subgraphs

**Goal**: Textual answer synthesis and comparative analysis.

**Reference**: `implementation.md` Section 3.2.

**Implementation**:
- `AnswerSynthesizer`: Generate text with citations.
- `CitationVerifier`: Logic to check if citations match source text.
- `Analyst/Proposer`: Planning node for multi-step comparison.

**Deliverables**: Two subgraphs wired to the Router.

## Task 3.5 — Numerical Subgraph (Polars)

**Goal**: Text-to-SQL execution.

**Reference**: `implementation.md` Section 3.2 (Numerical).

**Implementation**:
- `TextToSQL`: Prompt to generate Polars SQL.
- `ExecuteSQL`: **CRITICAL**: Run `pl.SQLContext` in `asyncio.to_thread` to avoid blocking main loop.
- `SQLVerifier`: Check for empty/error results.

**Deliverables**: A subgraph that can answer "What is the average of X?".
