# Epic 3: Agent Microservice Core (LangGraph)

**Context**: The agent microservice (in `services/agent-api`) hosts the LangGraph orchestration described in `docs/agents/implementation.md` and `docs/overview/system_architecture.md`. Epic 3 now includes graph-context planning, Valkey cache integration, SSE metrics, Guardrails, HITL pathways, and checkpoint persistence tied to the shared data layer.

**Key Design Docs**
- `docs/agents/implementation.md` §§3–5 (LangGraph nodes, HITL flows)
- `docs/overview/system_architecture.md` §3 (agent runtime + cache topology)
- `docs/data/schema_and_persistence.md` §3.6–3.8 (conversations, checkpoints, telemetry)
- `docs/interfaces/api_contracts.md` §3 (chat streaming contract)

## Task 3.1 — Agent State, Checkpoints & Shared Data Layer Integration

**Goal**: Define a fully typed `AgentState` that mirrors LangGraph checkpoints and repository DTOs, and wire persistence into `shared_data_layer`.

**What to do**
- Include `messages`, `graph_context`, `workflow_plan`, `cache_metadata`, `retrieval_metrics`, `vision_findings`, `interrupt_reason`, and `checkpoint_id` in the state schema.
- Implement checkpoint readers/writers that persist to `agent_state_checkpoints` and hydrate from `conversations`, `messages`, and `conversation_documents` (ensuring visibility overrides are enforced).
- Document how HumanGate interrupts, resume tokens, and HITL metadata flow through the same checkpoint channel.

**Deliverables**
- State module + repository helpers with integration tests (LangGraph resume, HITL resume).
- Updated doc narrative connecting these capabilities to Epic 1 tables.

## Task 3.2 — Retrieval, GraphRetriever & WorkflowPlanner Nodes

**Goal**: Expand the retrieval subgraph so it fuses vector search, keyword search, GraphRetriever, GraphSummarizer, and WorkflowPlanner outputs while computing cache keys.

**What to do**
- Implement `InputNormalizer` + `AttachmentScopeLoader` nodes that load documents/workflows from `shared_data_layer` and verify base-document auto-attach behavior.
- Build `GraphRetriever` (queries `graph_edge_evidence_rollup`, `graph_hot_entities`) and `GraphSummarizer` nodes that transform graph data into prompts.
- Add `WorkflowPlanner` that projects workflow graphs (from `workflow_versions` + `workflow_version_diffs`) into user-facing plans and caches them.
- Compute cache keys (Valkey) that combine `conversation_id`, document hashes, workflow version, and intent; record hits/misses in telemetry.

**Deliverables**
- LangGraph node implementations + tests.
- Documentation of cache key schema and when GraphRetriever must refresh views.

## Task 3.3 — Router, Guardrails, CacheWriter & HumanGate

**Goal**: Ensure routing includes guardrails, cache short-circuits, confidence gates, and HITL interrupts.

**What to do**
- `Router` must classify into `{Informational, Analyst, Numerical, Vision, Escalate}` and consult Guardrails (prompt policy, attachment validation, compliance filters).
- `CacheWriter` stores positive answers (serialized with citations + chunk ids) into Valkey and emits cache telemetry events.
- `HumanGate` node handles confidence thresholds, routes low-confidence or guardrail violations to HITL (pausing the LangGraph run via checkpoint), and records SSE events indicating the pause reason.

**Deliverables**
- Guardrail policy definitions, interruption handling logic, and tests that verify cache writes + guardrail enforcement.

## Task 3.4 — Subgraphs: Informational, Analyst, Numerical & Vision

**Goal**: Keep every modality covered, including the Vision subgraph and retries toward HITL.

**What to do**
- Informational & Analyst: `AnswerSynthesizer`, `CitationVerifier`, `AnalystPlanner`, `ComparisonSynthesizer` with telemetry hooks.
- Numerical: Text-to-SQL nodes (prompting, Polars execution in `asyncio.to_thread`, result validators) plus table/chart attachments.
- Vision: Nodes that route image-only requests through the Vision subgraph, leverage `image_caption` chunks, and produce multimodal answers with guardrail enforcement.
- All subgraphs must emit SSE metrics, include fallback-to-HITL pathways, and reuse shared retrieval context.

**Deliverables**
- Updated acceptance criteria ensuring each subgraph integrates GraphRetriever context, cache keys, and SSE telemetry.

## Task 3.5 — Streaming, Telemetry, and Caching Observability

**Goal**: Document and implement the SSE + metrics contract, cache observability, and integrations with `shared_data_layer`.

**What to do**
- Emit SSE events for every LangGraph transition (`task_start`, `task_end`, cache hit/miss, HITL pause/resume) plus Prometheus/OTel metrics for latency, token usage, and cache ratio.
- Feed retrieval + cache telemetry back into `retrieval_runs`, `chunk_metrics`, and `pillar_answers` writers via repository helpers.
- Keep Valkey connection pooling, rate limiter checks, and trace/span propagation consistent with `docs/overview/system_architecture.md`.

**Deliverables**
- Docs + code references for SSE envelopes, metric names, and cache dashboards.
- Integration tests covering cache hit, cache miss + write, and HITL resume scenarios.
