# Epic 2: Document Ingestion Pipeline

**Context**: Serverless workflow (Step Functions + Lambda) to transform raw PDFs into vectors and structured artifacts.

**Key Design Docs**:
- `docs/infrastructure/async_jobs.md` (Overview)
- `docs/overview/system_architecture.md` Section 2.1 (Diagram)
- `docs/interfaces/api_contracts.md` Section 2 (Event Payloads)

## Task 2.1 — Step Function & Preflight Lambda

**Goal**: Orchestrate the flow and handle validation/deduplication.

**Reference**: `api_contracts.md` Section 2.3 (Preflight).

**Implementation**:
- Define AWS Step Function (ASL) JSON definition.
- Implement `preflight-validator` Lambda:
    - Validate MIME type.
    - Check `content_hash` against DB (via `shared_data_layer`).
    - Deduplicate (if exists, skip to final).

**Deliverables**: Deployed Step Function that transitions from Start -> Preflight.

## Task 2.2 — Conversion & Chunking Lambdas

**Goal**: Convert PDF to Markdown and split into semantic chunks.

**Reference**: `api_contracts.md` Section 2.3 (Conversion/Chunking).

**Implementation**:
- `marker-converter` Lambda: Use marker or similar to get Markdown/JSON. Upload artifacts to S3.
- `chunk-builder` Lambda: Recursive character split (~500 tokens). Preserve structure (headers).

**Deliverables**: JSONL files in S3 containing text chunks.

## Task 2.3 — Embedding & Indexing Worker

**Goal**: Generate vectors and persist to Postgres.

**Reference**: `api_contracts.md` Section 2.3 (Embedding).

**Implementation**:
- `embedding-writer` Lambda:
    - Read chunks from S3.
    - Call Voyage AI API (voyage-3.5-lite).
    - Batch Insert into chunks table using `shared_data_layer`.

**Deliverables**: Vectors visible in Postgres chunks table.

## Task 2.4 — Graph Entity Extraction (Optional/Parallel)

**Goal**: Extract entities for the Knowledge Graph.

**Reference**: `data/knowledge_graph.md`.

**Implementation**:
- New Lambda step parallel to Embedding.
- Use LLM to extract Entities/Relationships from chunks.
- Upsert to `graph_entities` / `graph_edges`.

**Deliverables**: Populated `graph_entities` table.
