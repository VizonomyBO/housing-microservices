# Epic 6: Infrastructure & DevOps

**Context**: Terraform and CI/CD configuration.

**Key Design Docs**:
- `docs/infrastructure/infrastructure_and_deployment.md`

## Task 6.1 — Terraform Data Layer

**Goal**: Provision persistent storage.

**Implementation**:
- Aurora Serverless v2 (Postgres).
- Enable `pgvector` extension.
- ElastiCache Serverless (Valkey/Redis).
- S3 Buckets (raw, processed, reports).

## Task 6.2 — Compute Resources

**Goal**: Provision runtime environments.

**Implementation**:
- ECS Cluster (Fargate) for API and Workers.
- Step Functions state machine definition.
- Lambda definitions (container image based).

## Task 6.3 — CI/CD Pipelines

**Goal**: Automate testing and deployment.

**Implementation**:
- GitHub Actions `ci.yml`: Run `pytest` and `ruff`.
- GitHub Actions `cd.yml`: Build Docker images, push to ECR, update Terraform/ECS.
