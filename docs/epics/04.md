# Epic 4: API Gateway & Service Layer

**Context**: The FastAPI application (`services/agent-api`) that hosts the LangGraph runner and exposes REST endpoints.

**Key Design Docs**:
- `docs/interfaces/api_contracts.md` (REST Spec)
- `docs/security/auth_and_tokens.md` (Auth)
- `docs/overview/project_status.md` (Gateway Decision)

## Task 4.1 — FastAPI Skeleton & Auth Middleware

**Goal**: Setup the web server and security.

**Reference**: `auth_and_tokens.md`.

**Implementation**:
- Initialize FastAPI app.
- Implement JWT validation middleware (validate `sub`, `exp`, `iss`).
- Extract `user_id` and inject into `request.state`.

**Deliverables**: Running server returning 401 for unauthenticated requests.

## Task 4.2 — LangServe Integration

**Goal**: Expose the LangGraph agent via HTTP.

**Reference**: `implementation.md` Section 3.7.

**Implementation**:
- Use `langserve.add_routes`.
- Mount the compiled graph from Epic 3 at `/agent`.
- Ensure SSE streaming (`astream_events`) is enabled.

**Deliverables**: `POST /agent/stream` returns chunks.

## Task 4.3 — REST Endpoints (Chat & Upload)

**Goal**: Implement standard REST routes.

**Reference**: `api_contracts.md`.

**Implementation**:
- `POST /v1/documents/upload`: Generate S3 presigned URLs.
- `POST /v1/chat`: Wrapper around LangGraph invoke (if not using direct LangServe).
- `GET /v1/conversations/{id}`: Read from `shared_data_layer`.

**Deliverables**: Swagger UI showing these endpoints.

## Task 4.4 — Rate Limiter Integration

**Goal**: Protect LLM budget.

**Reference**: `overview/images/rate_limiter.png` and `system_architecture.md` 2.3.

**Implementation**:
- Implement Valkey (Redis) connection.
- Implement Token Bucket logic.
- Create Dependency for FastAPI routes (`Depends(RateLimiter)`).

**Deliverables**: 429 errors when exceeding limits.
