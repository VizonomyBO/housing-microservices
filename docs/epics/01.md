# Epic 1: Shared Data Layer & Persistence

**Context**: This package (`packages/shared_data_layer`) is the single source of truth for database models, migrations, and repository patterns. It is consumed by both the API and the Worker services.

**Key Design Docs**:
- `docs/overview/monorepo_structure.md` (Directory layout)
- `docs/data/schema_and_persistence.md` (Schema definitions)
- `docs/data/knowledge_graph.md` (Graph specific tables)

## Task 1.1 — Package Skeleton & Database Session Manager (Done)

**Goal**: Initialize the Python package structure and implement the Async SQLAlchemy session manager.

**Reference**: `monorepo_structure.md` Section 2.1 & 4.

**Implementation**:
- Create `packages/shared_data_layer/pyproject.toml` with dependencies (`sqlalchemy[asyncio]`, `alembic`, `pydantic`, `pgvector`, `asyncpg`).
- Implement `db/session.py` with `DatabaseSessionManager` (Singleton pattern, `asynccontextmanager`).
- Implement `config/settings.py` to read `DATABASE_URL`.

**Deliverables**: Installable pip package, working DB connection logic.

## Task 1.2 — Core Entity Models (Users & Documents) (Done)

The user table will be implemented elsewhere, but we will store the user id reference in the tables that need to communicate with it.

**Goal**: Implement SQLAlchemy 2.0 models for Identity and Document Registry.

**Reference**: `schema_and_persistence.md` Section 3.1 & 3.2.

**Implementation**:
- `db/models/documents.py`: Documents, IngestionJobs, Artifacts, ConversationDocuments.
- Ensure Mixins for UUID PKs and Timestamps are used (`db/base.py`).

**Deliverables**: Models reflecting the ERD.

## Task 1.3 — RAG & Graph Models

**Goal**: Implement complex models for Vector Storage, Knowledge Graph, and Workflows.

**Reference**: `schema_and_persistence.md` Section 3.4, 3.9, 3.10.

**Implementation**:
- `db/models/retrieval.py`: chunks (with pgvector column), chunk_metrics.
- `db/models/knowledge_graph.py`: graph_entities, graph_edges, graph_evidence, graph_communities.
- `db/models/workflow.py`: workflow_graphs, nodes, edges (ensure ltree extension support).

**Deliverables**: Models with correct indexes defined in `__table_args__`.

## Task 1.4 — Alembic Migration Setup

**Goal**: Embed Alembic inside the package so migrations are shipped with the library.

**Reference**: `monorepo_structure.md` Section 5.

**Implementation**:
- Configure `migrations/env.py` to use the async engine.
- Create a CLI entry point in `pyproject.toml` (`shared-data-layer migrate`).
- Generate `001_initial_schema` migration.

**Deliverables**: `shared-data-layer migrate` command successfully creates tables in a local Postgres container.

## Task 1.5 — Repository Layer & Pydantic DTOs

**Goal**: Abstract ORM logic behind Repositories and return Pydantic v2 objects (not ORM objects).

**Reference**: `monorepo_structure.md` Section 2.2 & 6.

**Implementation**:
- Create Pydantic schemas in `schemas/`.
- Implement `repositories/documents.py` (e.g., `get_document_with_chunks`).
- Implement `repositories/knowledge_graph.py`.
- Ensure eager loading (`selectinload`) is used before Pydantic validation.

**Deliverables**: Unit tests using the repositories returning Pydantic objects.
