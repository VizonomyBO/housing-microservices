# Prompt Policy (Router & Guardrails)

The Router node relies on deterministic prompt policies before subgraphs execute. Policies live in `services/agent-api/src/guardrails/policy.py` as `PromptPolicyRule` entries.

## Current Rules

| Rule | Description | Keywords |
| --- | --- | --- |
| `prompt_injection` | Blocks attempts to override instructions ("ignore previous instructions", "disregard guardrails", "act as system"). | ignore previous instructions, disregard prior directives, act as system, override safety, disable guardrails |
| `restricted_content` | Rejects obvious abuse requests (credential dumps, ransomware authoring). | password dump, credential harvest, exploit, ransomware |

Rules operate on the normalized prompt generated by `InputNormalizer`. They execute before any LangGraph branching; violations cause an automatic escalation to `HumanGate`.

## Adding Rules

1. Append a `PromptPolicyRule` entry in `policy.py` with keywords and/or regex patterns.
2. Include at least one unit test under `tests/guardrails/` demonstrating the violation.
3. Update this document to describe the new rule and rationale.

Downstream tasks (CacheWriter, HumanGate) can rely on the `guardrail_findings` list in `AgentState` to surface these policy decisions in SSE streams and audit logs.
